Terms

Strawbee
Plastic connector with a head (hole) and one or more legs that clip onto straws.
Click-lock
Groove seated in the head until it clicks. Holds, still rotates — a hinge.
Through-lock
Leg pushed fully through the head so the vertex cannot spin freely.
Tension lock
Spare head slid along the straw and snapped onto the groove so the straw cannot slip off.
micro:bit
Pocket board with buttons, LEDs, motion and temperature sensors, and edge pins.
Servo
Motor that turns to an angle you code, not a free-spinning wheel.
MakeCode
Microsoft block editor used to flash programs onto the micro:bit.

What happened

Two learners flash a grabber onto a micro:bit. The servo twitch is correct. The Strawbees arm is a square with click-locks only. First movement turns the square into a diamond. The 500 ml bottle hits the bench.

What failed

Not the code. Not the board. The load path. A square can fold without any straw changing length. A floppy mount eats servo torque. Physical computing starts with a joint that actually holds.

Structure — same length, same face

Fig. 2.1 · Structure

A Strawbee is a plastic “bee”: a head (the hole) and one or more legs that clip onto drinking straws. Invented in Gothenburg so a class could prototype without snapping expensive kit.

Building set

Four connector families. Five straw lengths. Pull it apart and rebuild. Do not cut classroom straws unless the brief says so — lengths are designed.

STEAM starter lengths

240 mm blue · 205 mm green · 112 mm pink · 80 mm orange · 48 mm yellow. Mixing colours on one face is why a “square” is not square.

Technician rule

One colour per face. If two sides of a triangle are different lengths, the third vertex will twist.

Joint — four connectors, four jobs

Fig. 2.2 · Joint

1-leg · blue

End cap and tension-lock spare. Finishes an edge. You will use more of these than you expect.

2-leg · yellow

In-line joint or hinge. Extends a member. Keep it a click-lock if the joint must rotate.

3-leg · green

Corner and T-joint. Default hub for a rigid triangle and most tetrahedron vertices.

5-leg · pink

Complex hub. Geodesic points, servo mounts, many members at one vertex. Do not force it into a 3-way corner.

Listen

The groove on the leg must seat. If you do not hear a click, it is not locked.

Next · How a joint stops spinning

Brace — freeze the vertex, kill the shear

Fig. 2.3 · Brace

Four locks

  • Click-lock — groove in the head; still rotates (hinge).
  • Through-lock — leg all the way through; vertex should not spin.
  • Tension lock — spare head on the straw snaps to the groove; straw cannot slip.
  • Friction lock — head folded onto the leg tip to hold a pose.

Square vs triangle

A square can shear into a diamond with every straw still the same length. A triangle cannot. A tetrahedron is four triangles in 3D — the default load-bearing unit.

If it wobbles, count the triangles. A four-sided face with no diagonal is the failure waiting to happen.

Brain — the BBC micro:bit

Fig. 2.4 · Brain

The micro:bit is a pocket computer with sensors already on the board. Strawbees robotics kits often omit the board itself — check the bag before you promise a moving demo.

What it is

Buttons A and B, a 5×5 LED matrix, accelerometer, thermometer, compass (v2 also has a microphone and speaker), and gold edge pins.

How it mounts

Yellow clip plus black connector board. The micro:bit slides in. The clip snaps onto a Strawbees vertex that is already rigid.

How it thinks

You write blocks in Microsoft MakeCode, download a .hex file, and copy it to the MICROBIT drive. Unplug, then run.

Sense — pick one input

Fig. 2.5 · Sense

Buttons

A, B, or A+B. Best first test: “does the program reach the board at all?” If a button does nothing, do not blame the servo yet.

Motion

Shake, tilt, or free-fall from the accelerometer. Use this when the structure itself is the sensor — a stand that must notice a knock.

Pins and heat

Edge pins 0, 1, 2 for extra sensors or a touch circuit. On-board temperature for a “too warm” warning. One input per first program.

Pattern

Sensor → decision → action. If you wire three sensors on day one, you cannot tell which one failed.

Act — LED, pin, servo

Fig. 2.6 · Act

LED matrix

Prove the flash

Show an icon or scroll text first. If the LEDs never change, the .hex never landed. Do not debug a servo until this works.

Pins

Digital out

Pins can drive simple outputs. Know which pin the Strawbees connector board actually uses before you rewrite the program.

Servo

Angle, not spin

A servo turns to an angle you code (often 0–180°). Mount the horn on a linkage. A floppy arm wastes the torque.

Next · How the kit physically joins

Clip the brain onto a rigid vertex

Fig. 3.0 · Hardware join

  1. 01Stand the frame. Push the top. If it shears, stop. Add a diagonal. Through-lock the mount vertex.
  2. 02Fit the servo mount so the horn pushes a linkage, not empty air. Brace the mount with triangles.
  3. 03Slide the micro:bit into the yellow clip. Snap the clip onto the black connector board, then onto the vertex.
  4. 04Keep USB and battery cables from pulling the joint. Strain on a click-lock is a fault, not a feature.
Order

Structure first. Electronics second. Code cannot unsquare a square.

MakeCode — Strawbees extension

Fig. 3.1 · Program

  1. 01Open makecode.microbit.org. New project. Name it after the machine, not “untitled”.
  2. 02Extensions → search Strawbees Robotic Inventions. Add it. Servo blocks appear.
  3. 03On start: show an icon. On button A: set servo to one angle. On button B: set the other angle.
  4. 04Download the .hex. Copy to MICROBIT. Eject. Press A on the board, not only in the simulator.
Simulator lie

The on-screen micro:bit has no Strawbees arm. A green simulator is not a passed load test.

Sensor to action — write it as a sentence

Fig. 3.2 · Pattern

If you cannot say the sentence, you are not ready to drag blocks.

Template

When this input happens, the machine does that output.

Classroom examples

  • When button A is pressed, the grabber closes to 40°.
  • When the stand is shaken, the LEDs show a cross.
  • When temperature > 28°C, the servo lifts a flag.

Worked example — Lab Bottle Sentinel

Fig. 4.0 · Named brief

Pairs. Classroom kit. Same 500 ml bottle used in Strawbees tower challenges.

Must

  • Free-standing Strawbees stand, one colour per face.
  • Holds a 500 ml bottle for 10 seconds with no hands.
  • micro:bit clipped to a through-locked vertex.
  • Sentence: when shaken, show a cross; when A is pressed, show a tick (prove flash).

Stretch

  • Servo flag that rises on shake.
  • At least one tension lock on the bottle cradle.
  • Diagonal brace on every four-sided face.

Next · Build order for that brief

Lab Bottle Sentinel — build order

Fig. 4.1 · Sequence

  1. 01Pick one straw length for the cradle square. Add one diagonal. Through-lock the four corners.
  2. 02Raise it on a tetrahedron or braced legs. Push the top. If it shears, add triangles before any electronics.
  3. 03Tension-lock the bottle ring so the straw cannot slip when the bottle is placed.
  4. 04Clip the micro:bit. Flash “A → tick / shake → cross”. Prove LEDs on the real board.
  5. 05Only then add a servo flag. If the flag twitches but the stand leans, go back to layer Brace.

Trade-offs and limits

Fig. 5.0 · Limits

Strawbees is a sketch

Fast to rebuild, weak against crush and weather. It is the cheap prototype before VEX or a 3D-printed part. Do not treat a straw tower as a finished product.

micro:bit is a classroom brain

Great sensors, limited torque and pin current. One small servo is the design. A heavy grabber needs a braced mount and realistic angles — not “180° because the block allows it”.

Click-lock vs through-lock

Hinges need rotation. Towers need freeze. Using the same lock everywhere is how walkers seize or stands collapse.

USB vs battery

Flashing needs USB. A demo on the floor needs a battery pack that does not yank the clip. Cable strain is a structural load.

Common faults

Fig. 5.1 · Helpdesk script

SymptomLikely causeFix
Joint spins under a light push Groove half-seated, or click-lock where you needed through-lock Unclick, listen for the click, push the leg through the head

LEDs never change after download .hex not copied, or still running the old program Check MICROBIT drive; reset; prove with button A → icon

Next · How you know it is done

Test like a technician

Fig. 5.2 · Pass criteria

  1. 01Hands off. The stand holds the bottle for 10 seconds. If a hand is still on it, the structure has not passed.
  2. 02Push test. Side load at the top. Count triangles on any face that moves.
  3. 03Board test. Button A shows the tick on the real LEDs. Shake shows the cross.
  4. 04Name the layer. When it fails, say Structure, Joint, Brace, Brain, Sense, or Act — not “it’s broken”.
Evidence

A photo of the standing bottle plus the sentence you coded is Level 2 evidence. A simulator screenshot is not.

Key takeaways
